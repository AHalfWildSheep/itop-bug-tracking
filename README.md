# AHalfWildSheep's Bug tracker

A simple yet complete bug tracker for iTop 

This extension provides a complete bug tracking system with support for issues, products, components, versions, and milestones. It includes a full lifecycle management system for tracking issues and dashboards to ease issue management.

## Features

- **Issue Management**: Track bugs, enhancements, and tasks with configurable priorities and severities
- **Product Organization**: Organize issues by products, components, and versions
- **Milestone Planning**: Plan releases and track progress with milestone management

Complete datamodel documentation available in the [docs](docs/documentation.md) folder.

## Installation

* Extract ahws-bug-tracking to your extension folder
* Run a setup

You can now use this extension by adding `Issue Manager` profile to a user and using the `Issue Management` menu entry

## Compatibility

Min version is 3.2.1 as I used newest color variables
